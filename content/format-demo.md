这一页把博客支持的各种格式都摆出来，写文章时照着抄就行。
（这页本身不会出现在「日志」里，看完可以删。）

## 一、普通文字

段落之间空一行就是新的一段。

**加粗**、*斜体*、~~删除线~~、`行内代码`。

换行不用管，写完一句直接回车，排版时会自动接上。

## 二、引言

> 真正独立思考的人，在精神上是独立的。
>
> 引用可以分好几段，左边会有一条细线。

还有一种备注块，写法是：

```
{{< note >}}
这里写一句想特别提示的话。
{{< /note >}}
```

## 六、自己上传的视频和声音

这两个是「短代码」，把文件名换成你自己传的文件名就行：

```
{{< video src="video-01.mp4" >}}

{{< audio src="voice-01.m4a" >}}
```

后台选视频时，系统也会自动帮你写好这一段。

## 七、油管（YouTube）

在 YouTube 视频网址里找到 `v=` 后面那一串（比如 `dQw4w9WgXcQ`），填进去：

```
{{< youtube dQw4w9WgXcQ >}}
```

下面是实际效果（如果你那边打不开 YouTube，这里会显示空白，属正常）：

## 八、数学公式

行内公式写在两个美元符号之间：当 $a \ne 0$ 时，方程 $ax^2+bx+c=0$ 有两个解。

单独一行的公式用两个美元符号包起来：

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

再长一点也没问题：

$$\sum_{i=1}^{n} \frac{1}{i^2} = \frac{\pi^2}{6}$$

## 九、代码
