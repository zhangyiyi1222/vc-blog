# 字体来源与授权

## SourceHanSerifCN-Regular.woff2

- 字体：思源宋体（Source Han Serif CN / Noto Serif CJK SC）中文子集
- 来源：<https://github.com/adobe-fonts/source-han-serif>
- 授权：**SIL Open Font License 1.1**（允许自由使用、修改与再分发），
  完整条款见同目录 [OFL.txt](./OFL.txt)

本文件是从本博客主题 `themes/minimal/static/fonts/` 中**复制**的一份副本，
只服务于 `/test/money/` 这个独立模块。博客原有的字体文件与字体配置没有任何改动。

模块中通过 `@font-face { font-family: "MT Serif CN" }` 引用，仅在本模块页面
（`assets/css/money.css`）生效，不影响博客正文使用的 `BlogSerifCN`。

## 正文字体

正文使用系统无衬线字体栈（Noto Sans SC / 苹方 / 微软雅黑 / system-ui），
不下载、不内嵌任何第三方正文字体。
