# 手机自己更新博客指南（一篇文章一个文件夹版）

## 核心原则
**一篇文章 = 一个文件夹。文章文字（index.md）和它的照片/视频/音频放在同一个文件夹里。**
GitHub 不会把视频配错文章，因为视频就在文章旁边。

## 步骤 A：先建“文章文件夹 + 文字”

1. GitHub 仓库 → **Add file → Create new file**；
2. 文件名（含文件夹路径）填：
   `content/posts/2026-09-06-my-video/index.md`
3. 内容粘贴下面的模板，然后 **Commit changes**：

```markdown
---
title: "视频标题"
date: 2026-09-06T12:00:00+08:00
categories: ["短视频"]
draft: false
---

（说明文字：这是什么时候、什么地方、里面是谁、为什么想留）

{{< video src="video-01.mp4" >}}
```

要点：
- 视频只写**文件名** `video-01.mp4`，不要写 `/uploads/` 之类路径；
- 模板里写的什么文件名，一会儿上传的视频就必须叫什么文件名；
- 照片用 `![说明](photo-01.jpg)`，音频用 `{{< audio src="voice-01.m4a" >}}`。

## 步骤 B：把视频上传到同一个文件夹

1. 等步骤 A 提交完成（仓库里会出现 `content/posts/2026-09-06-my-video/`）；
2. 点进这个文件夹 → **Add file → Upload files**；
3. 上传视频 `video-01.mp4`（和文章里写的名字一字不差）；
4. **Commit changes**，等约 1 分钟。

## 验证
打开文章地址：`https://你的域名/posts/2026-09-06-my-video/`
视频应该就出现在说明文字下方。

## 为什么不用 static/uploads？
`static/uploads` 适合“好几篇文章共用的图片/封面”；
单篇文章自己的视频/照片如果放那里，还得靠文件名猜属于哪篇，容易错。所以一律放文章自己的文件夹。
